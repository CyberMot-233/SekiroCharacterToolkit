# Sekiro Character Toolkit 0.10.10

## 0.10.10：追加 / 覆盖动画与同名重建

侧栏新增「追加 / 覆盖动画」。选择原提取包，再指定已有 Blender 工程或 CS2 addon / 模型名，加载动作后勾选需要处理的项目：未导出的动作加入，已导出的同名动作覆盖，未选择的动作保留。分批 Blender 工程选择其中一个具体文件即可。仅采样和烘焙选定动作，保留原模型、材质和其他动作；完成校验后提交，并保留回退备份。CS2 可同时追加动作音频，覆盖动作沿用实际音量，新动作默认 1 倍。

删除模型源文件后再次使用同名，工具会识别自身留下的声音、编译资源和声音注册，先备份到 addon/_sct_backups，再重建。精确匹配名称，wolf 不影响 wolf1；无法认领的陌生文件会显示具体路径，不自动覆盖。

新增动作需要原 source_native 动画包或游戏解包目录。Blender 目标需为本工具生成的层级骨架；自定义绑定或约束不兼容时会保留原件并说明原因。首次追加若需要额外 AFF 辅助骨，会迁移已有曲线以保持原姿态。修改前请关闭目标文件，完成后重新打开。

本版验证：Blender 12→13 动作及重复覆盖保存回读，11 个未选动作共 208,560 骨骼帧变换核对；CS2 增量至 14 动作 / 111 个声音事件编译回读；8 项同名/事务测试、真实残留副本和编译失败回滚通过。覆盖动作音量 10 与新动作音量 1 保持独立。修复 ffmpeg 将短 MP3 自动误判为视频的转码失败。以上为离线验证，游戏内播放和听感待实际验收。

## 下载和开始

1. 在 [Releases](https://github.com/Hoshino486/SekiroCharacterToolkit/releases/latest) 下载 **SekiroCharacterToolkit-0.10.8.exe**，不需要下载 Source code 压缩包。
2. 将 EXE 放到想使用的目录，运行后选择工具数据目录。工具链首次释放到该目录，以后校验并复用。
3. 在设置中选择已解包的只狼游戏数据、输出目录与缓存目录，扫描并选择角色和动作。
4. 如需 CS2 转换，另外安装 **CS2 Workshop Tools**，在工具中选择目标 addon。

已内置 .NET、Blender、Python、Pillow、NumPy、FFmpeg 及解析/音频运行组件，无需单独安装。**不包含只狼或 CS2 游戏素材，也不分发 Valve 官方编译器。**

单文件分发不等于运行时不释放文件：建议预留至少 4 GB 工具空间，模型输出另计。EXE 旁的 .location 仅记录数据目录；使用 --choose-dir 可重新选择。

## 主要功能

- **角色与武器**：提取模型、材质、骨架、动作和装备，修复层级、武器绑定和脸部相关数据；支持显示 AFF 辅助骨及清理无用骨。
- **贴图与音频**：贴图转换成不带 Alpha 通道的 RGB PNG，音频转换成 MP3。
- **动作选择**：按角色列出动作，自选或全选导出；可分别去除 X / Y / Z 轴根运动。
- **Blender 工程**：首次导出直接完成整理，可分批生成多个完整工程，或合并为包含全部动作的单工程。
- **缓存与续跑**：动作曲线逐个落盘，已完成动作释放后处理下一项；成功验证后清理本次任务缓存，失败保留便于续跑。
- **CS2 转换**：生成分类保存的 DMX、VMDL、材质、音频和事件，支持根运动限制、编译以及编译资源回读验证。
- **局部维修**：已有工程可修复动画末帧、武器绑定、CS2 绑定和部件显隐，避免无必要的全量重算。

## v0.10.8 修复

- 修复 CS2 部件组被禁用导致可选武器、刀鞘和衣装同时显示的问题。
- 根据已选动作的初始状态设置默认可见外观，并一致地重映射显隐事件编号。
- 新增「修复部件显隐（保留材质设置）」：先备份，仅修改 VMDL 部件与事件，不重新烘焙动作。
- 编译回读检查部件组启用状态、网格掩码、默认值及事件语义。
- 包含 0.10.7 的极小缩放武器父级修复与日志面板改进。

## 验证范围与限制

- 已完成 **17 动作 / 2,068 帧 / 159 骨**的离线回归，以及 265 个显隐事件重映射检查；源 DMX 几何和非显隐 VMDL 设置保持不变。
- 单 EXE 启动、内置依赖、330 次界面切换、日志面板与任务缓存清理测试通过。
- **尚未重跑全部角色和 1,434 个动作，也未完成 CS2 游戏内视觉验收。**这不是对所有游戏资源兼容性的保证。
- 缓存减轻逐动作处理中间内存压力，但全部动作最终合并到一个 Blender 文件仍需要足够 RAM；低内存机器建议分批。Windows 分页文件由操作系统管理，不随本工具缓存目录迁移。
- CS2 输出保留只狼角色/动画骨架，不等同于已重定向到官方 CS2 玩家骨架、开箱即用的玩家替换模型。
