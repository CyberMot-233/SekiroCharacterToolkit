# CS2 转换与故障排查 · 0.10.8

## 0.10.7 编译回读与日志修复

武器父骨在某些动作中用约 0.001 缩放隐藏模型，CS2 重建局部变换时会放大浮点误差。转换器现将其子骨连接到最近稳定祖先，并逐帧重烘局部动画；验证重建后的世界矩阵，保留网格、命名权重、骨骼及原始 Blender 工程。

「修复已完成的 CS2 模型」支持从旧版原始 DMX 迁移已完成绑定，核对源哈希并备份 source2、VMDL 和编译模型，不恢复未完成的全量动作。

回读默认检查全部整数帧。位置常规阈值仍为 0.002 Source 单位；CS2 的 CCompressedStaticVector3 即使禁用压缩仍会丢弃微小运动并以半精度存储，因此仅对已核对的该编码提供明确例外：区段源变化 ≤ 0.006、首帧量化不超过一个半精度 ULP 加 0.00003、总误差 ≤ 0.01。例外写入每个动作的 static_half_quantization，不能作为无损声明；旋转、缩放和动态位置通道仍执行严格检查。真实武器偏移仍会失败。

日志可自动换行并拖动上边界调高，关闭「跟随最新」后便于查看历史。状态栏只显示错误摘要，鼠标悬停可见完整异常；「复制完整日志」读取磁盘全日志，不只复制屏幕尾部。「打开日志文件」打开本次日志；日志位于设置的 cache/logs，成功清理缓存时仍保留诊断记录。

## 手动转换

1. 先得到包含 package.json 的完整角色提取包。
2. 打开「转换 CS2」，选择提取包、CS2 的 content/csgo_addons/项目目录，输入小写英文资源名（字母开头，可带数字和下划线）。
3. 全量用「转换全部动作」；部分动作取消它后加载列表、逐项勾选。搜索仅过滤显示，不改变选择。
4. ExtractMotion：TX/TY 为平面位移，TZ 为高度，RZ 为水平转向。默认 TX/TY，保留跳跃和转身。只改 ModelDoc 动作设置，不修改源 Blender 工程。
5. 勾选声音和编译，执行转换。Steam 的 CS2 Workshop Tools 是外部官方依赖，工具会从所选项目定位 resourcecompiler/resourceinfo，不随单 EXE 分发。只生成源工程可取消编译。
6. 在 ModelDoc 中打开生成的 VMDL，检查所需动作、脸部、装备显隐、音频和根运动；离线检查通过不等于游戏内验收。

导出页可设置提取后自动转换。它转换本次提取包全部动作；要分选请手动使用转换页。

## 分类目录

| content/addon 下目录 | 内容 |
|---|---|
| models/sekiro/characters/资源名 | VMDL、动作与事件 |
| rawmodels/sekiro/characters/资源名 | 原始 DMX、绑定换算结果、清单、报告与备份 |
| materials/sekiro/characters/资源名 | VMAT、RGB PNG、独立遮罩 |
| sounds/sekiro/characters/资源名 | CS2 编译用 PCM WAV |
| soundevents/soundevents_addon.vsndevts | 按资源名管理的声音注册区段 |

CS2 声音另生成 WAV/VSND，不用 MP3 冒充 VSND，也不替换提取包中的 MP3。官方编译产物位于同一安装的 game/csgo_addons/同名项目。

## 已完成项目的维修

点击「修复已完成的 CS2 模型」只复用 compile_export.json 中已完成的绑定动作，备份后重建，不恢复暂停的全量任务。缺少完整缓存会报错，不偷偷重新跑全部。

- 身体尖刺：当前兼容配置统一 8×UNORM8。不要改成 8×16 位高精度，也不要把八权重强裁成四权重。
- 武器悬空：避免混合不同权重精度；沿用同一绑定网格和动画。
- Bones: 0 / No bones in animation：不禁用整棵骨架；使用 DMX 导入骨架，不重新添加旧的显式 Skeleton 覆盖。
- ModelDoc 旧窗口：保存个人修改后关闭旧文档，重新打开生成 VMDL，避免把旧窗口的错误配置写回。
- 文件占用：相同贴图不会重复写，更新采用原子替换并短暂重试。仍失败时关闭正在编辑该文件的软件后重试，查看完整日志。
- 缺音：audio_report.json / conversion.json 会明确列出，不用无关声音替换。

## 适用范围与保留限制

生成保留只狼动作的 prop_dynamic / ModelDoc，不是 CS2 玩家骨架重定向，不包含第一人称手模或原游戏程序物理/行为系统。

最近角色测试集为 414 个完成动作、304 骨、9 网格组、99 挂点；其余全量绑定仍暂停，本次软件修复不恢复它。编译/回读验证、抽样 ModelDoc 外观与全游戏运行验收分别记录，不混称全部通过。

统一 8 位权重量化并非无损：三个动作 153 整数帧的所有顶点比较最大约 1.30 mm，旧 0.2 mm 目标未通过。近似法线、二级材质混合、SSS 等不保证与原引擎完全一致。

现有狼素材仍缺 c000001100、c000006000 等报告列出的声音；未伪造补音。全部 414 动作逐帧视觉、游戏内声音、光照和性能尚未完整验收。

报告状态 compiled_offline 只表示报告范围内的离线编译检查；complete_with_audio_gaps 表示存在音频缺口；failed 不是可当作通过的版本。

0.10.3 的 Blender 分批不改变 CS2 原始输入。转换页仍选择父级完整提取包，直接读取原生动作，不需要先合并 Blender 分批工程。


## 0.10.4 直接导出

新 Blender 导出由 build_character.py 直接写好最终骨架、装备和动作，仅保存一次；verify_final.py 只读重开，不再调用清理/层级/根运动/显示设置的多次存盘流程。旧工程维修按钮仍提供显式后处理，不会在新导出中自动执行。

CS2 仍读取同一原生父级提取包，分批 Blender 输出不改变源动画和音频索引。本次仅验证 Blender 导出链；没有重跑全量 CS2 绑定换算或进行新的 CS2 运行时验收。


## 0.10.8 备用武器悬空 / 衣装叠加

BodyGroupList 不可禁用：它负责隐藏未参与当前动作的备用刀、刀鞘和互斥衣装。全部渲染会显示未动画驱动的参考姿态部件，不能靠移动正常武器来解决。新版默认取已选动作中最常见的真实初始外观，同时重新映射每个动作的显隐事件选项编号。

「修复部件显隐（保留材质设置）」只修改分组开关、默认选项顺序和对应显隐事件；保留已有材质组、声音事件、根运动和全部 DMX。修复前自动备份 VMDL、VMDL_C 和验证报告。完成后关闭旧 ModelDoc 文档且不要再保存旧内容，再重新打开生成 VMDL。普通无动画预览使用默认外观；切换动作后播放以触发对应事件。

0.10.8 回读新增对 BodyGroupList 启用、CTRL 网格名称/索引、DATA 网格分组位、默认选择与全部事件语义的检查，不再仅验证事件字节存在。图像回归使用编译动画重建姿态、DMX 几何及实际部件状态，是离线可视检查，不等同于 ModelDoc 或游戏内验收。
# 逐动作音量（0.10.9）

- **已有模型**：进入「转换 CS2」，选择原 CS2 addon 和模型资源名，点击「加载现有模型音量」。无需重新提取角色，也不要求原提取包仍在原路径。
- 每个动作右侧是音量倍数，范围 **0–10**：0 静音，1 原始增益，2 两倍增益；这是事件的绝对数值，不是对当前音量反复乘算。高增益可能产生削波或受到引擎混音限制，应以试听为准。
- 可单独输入，也可以在「批量音量」输入数值后点击「应用到勾选动作」。筛选只隐藏列表，不会取消隐藏动作的勾选；批量操作针对全部勾选项，不受「转换全部动作」选项影响。
- 点击 **「仅更新勾选动作音量」**。启用「使用此项目安装的 Workshop Tools 编译」时，更新声音事件并编译 VMDL / VSNDEVTS，回读验证后提示成功；关闭时仅生成源文件。
- 若一个动作已有多个不同音量，会显示「混合音量」，须明确输入音量后才能批量统一。没有声音事件的动作会明确标注，调节不会凭空产生声音。
- **新转换**：先加载提取包动作列表，在每行设置音量后正常转换；未设定动作默认沿用已保存模型配置，没有配置时使用 1。
- 同一音效可被多个动作共享，本功能生成动作专属声音事件来隔离音量，复用相同音频文件，保持事件帧、挂点、部件显隐、根运动、材质和 DMX 不变。
- 成功结果写入 rawmodels/sekiro/characters/模型名/reports/audio_volume.json；持久配置为同目录上一级 audio_volumes.json。备份位于 rawmodels/sekiro/characters/模型名/backups/audio_volume_时间。
- 重新打开 ModelDoc 后播放动作试听。界面/编译验证不代表已听过实际响度；不必全局替换 soundevents_addon.vsndevts 的 volume。

# 0.10.10：同名删除重建、增量动画

「删除 wolf 后仍报重名」通常是 models 已删，但 sounds、rawmodels、materials、game 编译目录或共享声音注册仍有记录。新版本在同名 VMDL 已不存在、且能通过工具所有者记录或精确声音注册标记认领时，先将残留移到 addon/_sct_backups/wolf_recreate_时间，再允许重新导出。wolf 与 wolf1 精确隔离。声音注册不完整或残留来源不明时，在移动前报出具体问题；移动或注册更新失败会回滚已移动项目。已有 VMDL 的不同来源包不会被误当作残留。

已有模型增加动作请使用「追加 / 覆盖动画」，不需要删除模型。选中同名动作替换、新动作加入，未选动画节点、根运动、材质、网格和挂点保留。仅对所选动作导出及换算；临时生成的验证网格不会覆盖目标网格。动作清单、绑定缓存和声音清单同步更新，后续维修可识别新增动作。勾选编译后回读全部已登记动作与声音事件；离线验证不代表游戏内播放和听感已验收。
